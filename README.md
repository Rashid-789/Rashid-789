# Rashid Khan

Backend and mobile developer based in Rawalpindi, Pakistan.

I mostly work with agencies that already have designers and frontend developers but need someone on the backend. That usually means the API, the database, payments and the admin panel, and sometimes the Flutter app as well. I've been doing this for a little over three years.

Nearly all of my work sits in private client repos, which is why my GitHub looks quiet. Some of it is written up on my [portfolio](https://rashidiya-portfolio.vercel.app).

## Recent projects

- **[Autonect](https://rashidiya-portfolio.vercel.app/work/autonect)**, a UK car-parts marketplace. Buyers enter a registration number, the app pulls the car's details from the DVLA API, and the request goes out to matching suppliers. Flutter, Node.js, PostgreSQL, Stripe.
- **[Hareer+](https://rashidiya-portfolio.vercel.app/work/hareer-plus)**, a multi-vendor platform in Libya for restaurants and clothing stores. I built the backend and the admin panel. NestJS, PostgreSQL, Redis, BullMQ.
- **[Chassis Doctor](https://rashidiya-portfolio.vercel.app/work/chassis-doctor)**, a vehicle inspection app that's [live on Google Play](https://play.google.com/store/apps/details?id=com.chassisdoctor.app). I built the backend and admin panel, and before launch I audited the Supabase row-level security and fixed 20 critical issues.
- **[Luumilo](https://rashidiya-portfolio.vercel.app/work/luumilo)**, a parenting app from the Netherlands. I worked on giving its AI assistant memory between sessions, and built the React frontend, admin panel and AWS deployment.
